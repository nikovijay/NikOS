# Playbooks

nikos-mode matches the request against "Use when", top to bottom, and runs the
first match. Packs add rows here as they ship new playbooks.

| Playbook | File | Use when |
| --- | --- | --- |
| idea-to-blueprint | `idea-to-blueprint.md` | The person has a new product idea, or wants to start a project from scratch and there is no story map yet. |
| onboard | `onboard.md` | The person has just installed nikOS, asks to set it up or get started, or wants to organise their company, department, team or product with it, and the folder has no `intent/` or `planning/` yet. |
| company | `company.md` | The person wants to set nikOS up for a whole company or department: a company plan, settings every team inherits, and departments joining. |
| start | `start.md` | The person wants to set nikOS up in this repo, or get started, and there's no `intent/` folder yet (or they ask to set it up again). |
| map-existing | `map-existing.md` | The person wants a story map of a product that already exists: "map what this repo does", or nikOS on an existing codebase. |
| video | `video.md` | The person asks for a video: an explainer, product tour, demo, launch or social clip, or to edit or re-render one. Needs the Video pack. |
| validate | `validate.md` | The person wants to test or validate an idea with real people, or draft outreach, a post or a demo script for it. |
| planning | `planning.md` | The person wants to plan a period, set OKRs or key results, frame or review a bet, check in on key results, or see a planning dashboard. Needs the Planning pack. |
| tracker | `tracker.md` | The person wants to connect Jira, Linear, GitHub or GitLab issues, bring a tracker's backlog in, link stories to tickets, or bring the tracker and the story map back in step. |
| build-a-story | `build-a-story.md` | The person asks to build, do or pick up the next story, or a story by its id. |
| answer | `answer.md` | The person asks a question about the product, a story, a plan or a decision, and nothing in the repo needs to change. |
| change | `change.md` | The person asks to add, fix, change or remove something in the repo: code, tests, docs or specs. |
